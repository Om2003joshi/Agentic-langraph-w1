# Streamlit Session State Explained (Chatbot Example)

## 1. What is Streamlit?

Streamlit is a Python framework used to build web apps easily.

Important behavior:

* Every user interaction (button click, input, etc.) → **entire script reruns**
* This means normal variables get reset every time ❌

---

## 2. Problem Without Session State

Example:

```
messages = []
```

What happens:

* User sends message → script reruns → `messages = []` again
* Chat history is LOST

---

## 3. Solution: st.session_state

`st.session_state` is like a **persistent dictionary (memory)**

Example:

```
st.session_state["messages"] = []
```

This data:

* Survives reruns ✅
* Stores chat history ✅

---

## 4. Basic Chatbot Code

```
import streamlit as st

st.title("Simple Chatbot")

# Step 1: Initialize memory
if "messages" not in st.session_state:
    st.session_state["messages"] = []

# Step 2: Display chat history
for msg in st.session_state["messages"]:
    with st.chat_message(msg["role"]):
        st.write(msg["content"])

# Step 3: Take user input
user_input = st.chat_input("Type your message...")

if user_input:
    # Step 4: Store user message
    st.session_state["messages"].append({
        "role": "user",
        "content": user_input
    })

    # Step 5: Generate bot response
    bot_response = f"You said: {user_input}"

    # Step 6: Store bot response
    st.session_state["messages"].append({
        "role": "assistant",
        "content": bot_response
    })
```

---

## 5. Step-by-Step Execution

### First Run:

```
st.session_state = {}
```

After initialization:

```
{
  "messages": []
}
```

Loop:

```
for msg in []
```

Output:

* Nothing displayed

---

### After User Types "Hello"

We append:

```
{
  "role": "user",
  "content": "Hello"
}
```

Memory becomes:

```
{
  "messages": [
    {"role": "user", "content": "Hello"}
  ]
}
```

---

### After Bot Response

Memory:

```
[
  {"role": "user", "content": "Hello"},
  {"role": "assistant", "content": "You said: Hello"}
]
```

---

## 6. How Display Works

Loop:

```
for msg in messages:
```

Iteration 1:

```
msg = {"role": "user", "content": "Hello"}
```

Output:
User bubble → Hello

Iteration 2:

```
msg = {"role": "assistant", "content": "You said: Hello"}
```

Output:
Bot bubble → You said: Hello

---

## 7. Key Concept (Very Important)

Streamlit works like this:

```
User input → Script reruns → UI rebuilds
```

BUT:

```
st.session_state → does NOT reset
```

So chat history stays.

---

## 8. Mental Model

Think:

```
st.session_state["messages"] = Chat Memory
for loop = Display all messages
```

---

## 9. Common Mistake

Wrong:

```
messages = []
```

Correct:

```
if "messages" not in st.session_state:
    st.session_state["messages"] = []
```

---

## 10. Advanced Usage

You can store anything:

```
st.session_state["thread_id"]
st.session_state["model"]
st.session_state["memory"]
```

Used in:

* Chatbots
* LLM apps
* LangChain / LangGraph systems

---

## 11. One-Line Summary

st.session_state = Persistent memory in Streamlit apps across reruns

---

## 12. Final Understanding

* Without session_state → chatbot forgets everything
* With session_state → chatbot remembers conversation
* Loop displays stored messages
* Append adds new messages
